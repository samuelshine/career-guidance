## Overview

**CareerOps** is an AI-powered career guidance platform built for Christ University. It uses a **Git metaphor** to model career paths: users upload resumes, "branch" into target roles, discover skill "conflicts" (gaps), resolve them via AI coaching, and get "headhunt" evaluations from a recruiter agent.

## Domain Model (Git Metaphor)

| Domain Concept | Git Metaphor | Purpose |
|----------------|--------------|---------|
| Career path | **Branch** | A potential career direction (e.g., "Google PM Path") |
| Skill gap | **Conflict** | Missing skill detected when comparing profile to job |
| Learning plan | **Patch** | Action items + resources to close a skill gap |
| State snapshot | **Commit** | Versioned snapshot of career state for rollback |
| Combining paths | **Merge** | Merging two branch conflict lists for a combined view |

## Data Flow

1. **Resume Upload:** User uploads PDF → `pypdf` extracts text → `SimpleResumeIngestor` (Gemini) extracts structured profile → saved as `CareerState`
2. **Branch Creation:** User provides target role + JD → `BranchingEngine` (Gemini) performs semantic diff → generates `Conflict[]` with `Patch` plans → state committed
3. **Coaching:** User selects a conflict → `CareerCoach` (Gemini) responds with persona-based advice
4. **Recruiter:** User checks readiness → `RecruiterAgent` scores profile → generates HIRE/WAITLIST/REJECT with personalized message
5. **Interview:** User starts mock interview → `InterviewAgent` generates questions → evaluates answers with score + feedback
6. **Rollback:** Any commit can be rolled back by restoring its snapshot

## Conventions

**State Management:** React `useState` + prop drilling (no global store)
**Styling:** TailwindCSS 3.x with shadcn/ui components
**AI Pattern:** LangChain prompt → LLM → output parser chains per agent
